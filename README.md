# When Correct Answers Carry Invalid State

An LLM agent can give the right final answer and still pass incorrect or incomplete information to the next step. This repository uses saved responses from 7,200 primary experimental runs to check answer correctness, the state passed forward, and whether a downstream program can act on it.

[Paper PDF](paper/paper04.pdf) · [Reproduction instructions](reproduction/README.md) · [Download the release](https://github.com/Pure-Bliss-734/paper-04-correct-answers-invalid-state/releases/tag/v2026.11.26)

The distribution includes saved responses, bounded state, scorers and receipts. Availability of intermediate model responses varies across the historical runs.

The release contains the manuscript PDF and the reproduction ZIP.
